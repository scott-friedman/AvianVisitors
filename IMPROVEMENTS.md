## Executive summary — top 10 by impact

1. **P1 — The public repo publishes the SSH attack surface its own security model assumes is hidden.** The repo is PUBLIC (`gh repo view`), yet the tunnel hostname `bird-ssh.foobos.net` AND the username `inky` are committed in `CLAUDE.md:90`, `PLAN.md:139`, `DEPLOY-SUDBURY.md:18`, `pi/README.md:230,243` — while the stated model is "the tunnel hides SSH from port-scanning, so a strong password is the gate." Cheapest fix: make the fork private (the Pi's `pi/update.sh` pull then needs a read token/deploy key); alternatives: scrub the hostname/username to placeholders, or add SSH keys / Cloudflare Access. *(→ Security)*
2. **P1 — `POST /api/frame-config` is unauthenticated and writes D1 on every call** (`worker/src/index.js:518-526`). Abuse chains: burn the pooled D1 daily write quota until real detection ingest fails; flip `window_hours` between valid values so every 5-min Pi poll is a frame-cache miss → ~288 metered Browser Rendering renders/day (budget is ~10 min/day) → the panel freezes on stale; plus it silently changes what the physical frame at Dad's displays. *(→ Security)*
3. **P1 — One failed poll blanks the site.** `avian/frontend/apt.js:2138-2141` assigns `DATA.stats/lifelist/timeseries/firstseen` unconditionally from fetches that `.catch()` to `null` — one transient worker 500 (the exact 07-03 burst pattern) wipes the atlas to "No birds detected yet" until the next good tick. The other four slices are correctly guarded four lines later. *(→ Error handling)*
4. **P1 — Atlas click listeners accumulate ~120/hour.** `renderAtlas` adds `grid.addEventListener('click', …)` on the persistent `#atlasGrid` on every render (`apt.js:2064-2078`), and it renders every 30 s poll. A spectrogram click then fires N handlers → N play/stop toggles and N `new Audio()` loads. *(→ Architecture/correctness)*
5. **P1 — Zero CI runs on this fork and zero tests cover any custom code.** Both workflows target `main` while all work is on `avian-visitors` (`.github/workflows/python-app.yml:7-10`, `python-ci.yml:4-8`); the Cloudflare deploy workflows were deleted (commit `10cadfb`) but `PLAN.md:50` and `DEPLOY-SUDBURY.md:39` still claim they exist. None of the incident-hardened logic (tz math, poll cache, D1 retries, ingest dedupe, build-site hashing) has a single test. *(→ Testing, DX)*
6. **P1 — The forwarder still drops detections in any sustained worker outage.** `pi/detection-forwarder.py:194-204,253-255`: retries span ~20–80 s, then the offset advances regardless — a multi-minute 500 burst (the documented 07-03 shape) loses every detection inside it. Near-free fix: `sys.exit(1)` on final failure; systemd `Restart=always` + the saved offset + the worker's `(sci,ts)` dedupe turn BirdDB.txt itself into a spool. *(→ Error handling)*
7. **P2 — Junk query params bypass the poll micro-cache entirely.** The cache key is the raw query string (`worker/src/index.js:743`), so `/api/recent?hours=1000000&x=<rand>` is a guaranteed miss running a whole-table GROUP BY — the 07-03 D1 overload, attacker-triggerable on demand. Key on the clamped known params only. *(→ Security/Performance)*
8. **P2 — One index pin is misapplied and makes the facts RETURN join ~4× slower** (`worker/src/index.js:915-920`). Verified with `EXPLAIN QUERY PLAN` + benchmark: the pin forces `SCAN p` × ts-range instead of the perfect `idx_detections_dedupe (sci=?, ts>?)` seek. Remove `INDEXED BY` from this one query. *(→ Performance)*
9. **P2 — The worker contains zero logging** (no `console.*` anywhere in `index.js`). Rare-clip archive failures are swallowed forever (`:312`), exhausted D1 retries leave no trace (`:106-115`), frame render failures fall back silently (`:605-607`), cron errors vanish (`:121`). Four `console.error` sites + Workers Logs would have made the 07-03 incident diagnosable in minutes. *(→ Observability)*
10. **P2 — A from-scratch rebuild gets the wrong repo.** `newinstaller.sh:47` clones upstream `Twarner491/AvianVisitors`, not the fork — a disaster-recovery reinstall produces a box with none of the `pi/` glue, mandatory 512 MB tuning, or update path until a manual remote swap buried in CLAUDE.md. One-word change. *(→ DX)*
